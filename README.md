# KES EDUTECH

A modern and responsive EdTech landing page built using React and Vite.

## Features

- Responsive design
- Modern UI
- Course showcase
- About section
- FAQ section
- WhatsApp enrollment
- Scroll to top button
- Contact footer

## Tech Stack

- React.js
- CSS3
- React Icons

## Installation

```bash
git clone https://github.com/<your-username>/KES-EDUTECH.git
cd KES-EDUTECH
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```
